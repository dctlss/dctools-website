Inspect any Discord user or bot profile to analyze creation timestamps, badges, custom banners, avatars, and raw API metadata.

How do I find someone's User ID?

1. In Discord, go to User Settings > Advanced and enable Developer Mode.
2. Right-click any user's profile picture or username in chat or a server member list.
3. Click "Copy User ID" and paste it above.

         About Discord Profile Inspection
      

      

        

          Every Discord account and bot is tied to a unique numeric identifier known as a Snowflake ID. By parsing these IDs, developer tools can accurately extract creation timestamps, analyze user badges, and inspect profile branding elements like custom banners, avatar formats, and accent colors.
        

        

          This utility provides a seamless way to check account ages and look up public profile properties without needing complex API queries or developer bots.
